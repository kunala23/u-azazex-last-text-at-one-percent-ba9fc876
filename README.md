A dying phone's final text message at one percent battery, written by `main.ts` to `/output/entry.txt`.

## Entry

> 1%. Last confession: your photos aren't lost. I hid them in a folder called Taxes 2019. You never open it. Goodbye, tell the charger I loved it.

## Run

```sh
node main.ts
cat /output/entry.txt
```

No network, no secrets, no dependencies — just Node 22+ and one deterministic string, 1–200 characters.
